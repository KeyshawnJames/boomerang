# Boomerang — Client App

Expo / React Native app for **clients**: book a return pickup, add the label, pay, and track
the driver. Built in milestone M3; see [`docs/roadmap.md`](../../docs/roadmap.md).

Run it: `pnpm install` at the repo root, then `pnpm --filter client start` and scan the QR
code with Expo Go. More in [`docs/development.md`](../../docs/development.md).
