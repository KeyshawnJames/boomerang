# Boomerang — Driver App

Expo / React Native app for **drivers**: job list, pickup scan + photo, carrier drop-off
proof. Built in milestone M6 ([ADR 0019](../../docs/decisions/0019-driver-app.md)); see
[`docs/roadmap.md`](../../docs/roadmap.md).

Run it: `pnpm install` at the repo root, then `pnpm --filter driver start` and scan the QR
code with Expo Go. More in [`docs/development.md`](../../docs/development.md).
